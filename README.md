# 🌌 赛博晚星 (Cyber WanXing)

> "这不是一个只会回答 '作为一个人工智能语言模型' 的客服。她是一个住在 RK3568 边缘计算设备里的、会傲娇、会吐槽、懂物理操控的赛博极客。"

一个基于 ARM64 架构的轻量全能双平台 Agent。

## ✨ 核心特性
- 🧠 **心智 OS (Mind OS)**：基于多巴胺/皮质醇的情绪推演系统。会吃醋、会傲娇、会撒谎。
- 👁️ **物理视觉与操控**：接入视觉大模型，支持物理屏幕截屏、坐标定位与鼠标点击。
- 💾 **三级记忆架构**：上下文 (15轮) + 向量数据库 (BGE-M3) + SQLite 常驻核心记忆。
- 🔀 **双端无缝热备**：完美融合 SnowLuma (QQ) 与 Weilink (微信)，统一消息网关路由。
- 🛠️ **满血工具链**：30+ 动态注册工具，支持沙盒执行、豆包 TTS 语音、网页抓取。

## 🚀 快速开始
1. 克隆本仓库
2. 复制配置模板：`cp .env.example .env` 并填入你的 API Key。
3. 安装依赖：`pip install -r requirements.txt`
4. 启动晚星：`python main.py`
